# COVID-19 Data Analysis — SQL & Tableau

## Project Overview

This project analyzes COVID-19 cases, deaths, and infection rates
using SQL Server and Tableau.

The project was developed as a practical exercise to strengthen
SQL data analysis skills and data visualization.

## Tools

- SQL Server
- Tableau
- Excel

## Dataset

The dataset contains COVID-19 deaths and vaccination data by country
and date.

## SQL Analysis

The analysis includes:

- Data exploration
- Filtering and aggregation
- GROUP BY
- JOINs
- Window functions
- CTEs
- Temporary tables
- Views

## Tableau Dashboard

The SQL results were prepared and exported to Excel before being
connected to Tableau for visualization.

![COVID-19 Dashboard](Images/covid-dashboard.png)

## Key Analysis

The project explores:

- Global COVID-19 cases and deaths
- Death percentage
- Infection rate by country
- Deaths by continent
- Infection trends over time
